# ABP Cafe · Sale Monitor (Au Bon Pain)

หน้าเว็บ Sale Monitor แบบเรียลไทม์ของ Au Bon Pain — ยอดขายวันนี้เทียบเมื่อวาน ณ เวลาเดียวกัน, รายชั่วโมง,
อันดับสาขา, ประเภทร้าน, วิธีจ่ายเงิน, โปรโมชั่น, สมาชิก, หมวดสินค้า และสินค้าที่ซื้อคู่กัน

- หน้าเว็บ: https://mudandgreyhound.github.io/abp-cafe-sale/ (ต้อง login)
- ข้อมูลมาจาก API `https://abp-cafe-sale.mobile1234.site` ซึ่งต้องใช้ token จากการ login — ใน repo นี้มีเฉพาะหน้าเว็บ ไม่มีข้อมูลยอดขายหรือรหัสผ่าน
- รีเฟรชอัตโนมัติทุก 30 วินาที (ข้อมูลจาก CM POS อัปเดตทุก ~30 วินาที)
